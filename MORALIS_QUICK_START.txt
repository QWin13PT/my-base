┌───────────────────────────────────────────────────────────────────────┐
│ STEP 1: GET YOUR API KEY                                              │
└───────────────────────────────────────────────────────────────────────┘

1. Visit: https://admin.moralis.io/settings/api-keys
2. Sign up or log in
3. Copy your API key


┌───────────────────────────────────────────────────────────────────────┐
│ STEP 2: CREATE .env.local FILE                                        │
└───────────────────────────────────────────────────────────────────────┘

Create a file named .env.local in your project root with:

NEXT_PUBLIC_MORALIS_API_KEY=your_api_key_here

⚠️  IMPORTANT: Replace "your_api_key_here" with your actual API key!


┌───────────────────────────────────────────────────────────────────────┐
│ STEP 3: TEST THE INTEGRATION                                          │
└───────────────────────────────────────────────────────────────────────┘

Run this command to test if everything works:

npm run test-moralis


┌───────────────────────────────────────────────────────────────────────┐
│ STEP 4: START DEVELOPMENT SERVER                                      │
└───────────────────────────────────────────────────────────────────────┘

npm run dev

┌───────────────────────────────────────────────────────────────────────┐
│ AVAILABLE API FUNCTIONS                                                │
└───────────────────────────────────────────────────────────────────────┘

Wallet Data:
  • getWalletTokenBalances(address)    - ERC20 tokens
  • getWalletNativeBalance(address)    - Native ETH
  • getWalletPortfolio(address)        - Complete portfolio
  • getWalletTransactions(address)     - Transaction history
  • getWalletNFTs(address)             - NFT collection
  • getWalletSummary(address)          - Everything

Token Data:
  • getMoralisTokenPrice(address)      - Token price + 24h change
  • getTokenMetadata(addresses)        - Token info
